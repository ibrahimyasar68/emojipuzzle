# Asset licences

Every asset that ships with this app is listed here, with its source and the
attribution it requires (§33).

## Puzzle artwork — OpenMoji

- **Source:** <https://openmoji.org> · <https://github.com/hfg-gmuend/openmoji>
- **Licence:** CC BY-SA 4.0 · <https://creativecommons.org/licenses/by-sa/4.0/>
- **Required attribution**, to be shown in the app's about/parent area and in
  the store listing:

  > Emoji artwork: OpenMoji — the open-source emoji and icon project.
  > Licence: CC BY-SA 4.0

- **Share-alike:** using these images unmodified only requires the attribution
  above. If the artwork itself is adapted (recoloured, redrawn, combined into a
  new image), the adaptation must also be released under CC BY-SA 4.0. Cropping
  a picture into puzzle pieces at runtime is not a distributed adaptation, but
  editing the source files is.

Files were taken from `color/618x618/` and renamed to the naming convention in
§34:

| File         | Emoji | Codepoint |
| ------------ | ----- | --------- |
| `apple.png`  | 🍎    | U+1F34E   |
| `cat.png`    | 🐱    | U+1F431   |
| `ball.png`   | ⚽    | U+26BD    |
| `banana.png` | 🍌    | U+1F34C   |
| `dog.png`    | 🐶    | U+1F436   |
| `bus.png`    | 🚌    | U+1F68C   |
| `car.png`    | 🚗    | U+1F697   |
| `sun.png`    | ☀️    | U+2600    |
| `lion.png`   | 🦁    | U+1F981   |

### Resolution note

OpenMoji's largest raster export is 618×618. §34 targets 1024×1024; upscaling a
618 px PNG would add file size and no detail, so the files are kept at their
native size. A genuine 1024 px source means re-rendering OpenMoji's SVGs
(`color/svg/<CODEPOINT>.svg`) with a rasteriser such as `librsvg`, which is not
installed on this machine.

### Background note

The artwork has a transparent background, as §34 requires. The solid colour
behind each puzzle piece is painted by the app at runtime (see
`lib/features/puzzle/data/puzzle_palette.dart`), so the asset files stay
unmodified.

## Audio — sound effects

- **Source:** generated by this repository, `tool/generate_sfx.dart`
- **Licence:** none needed; they are this project's own output
- **Attribution:** not required

`dart run tool/generate_sfx.dart` synthesises the four effects and writes them
to `assets/audio/sfx/`. Re-running it reproduces the same bytes, so the files
can be regenerated instead of being treated as binary artefacts.

| File                  | What it is           | Length |
| --------------------- | -------------------- | ------ |
| `piece_snap.wav`      | a piece landing      | 120 ms |
| `puzzle_complete.wav` | the picture finished | 640 ms |
| `balloon_pop.wav`     | a balloon popping    | 150 ms |
| `hint.wav`            | "look at this one"   | 400 ms |

They are deliberately plain: short, soft and in tune, so nothing startles a
3-year-old (§22, §27). Replacing them with recorded effects is a drop-in
change — same filenames, same folder — but anything downloaded must be listed
here first, with its licence and attribution.

## Voice and music

None. If either is ever added it goes in `assets/audio/voice/` and
`assets/audio/music/`, and gets its own entry here before it ships.
